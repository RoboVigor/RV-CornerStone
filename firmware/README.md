# CornerStone LED — CubeMX migration

## Scope and versions

Standalone bare-metal HAL milestone; no RTOS or legacy robot framework is linked.
Legacy directories in this branch are baseline reference only; the CubeIDE project below is the sole firmware build entrypoint.

- MCU: STM32F427IIHx, UFBGA176 (user-confirmed package).
- STM32CubeMX 6.18.1, STM32CubeF4 1.28.3, STM32CubeIDE 2.2.0.
- Observed host: macOS 26.6.1 arm64. Launch/configuration checks passed; this is not a claim of official OS support.
- HSE crystal mode, 12 MHz software baseline; PLL M=12, N=360, P=2; SYSCLK/HCLK 180 MHz; APB1 45 MHz, APB2 90 MHz.
- Voltage scale 1, OverDrive, Flash latency 5 generated by CubeMX. HSE/PLL failures enter Error_Handler, not an HSI fallback.
- PLLQ=8 gives 45 MHz: USB is not enabled. Revisit clock planning before adding peripherals requiring exactly 48 MHz.
- SWD: PA13/PA14. LEDs: PG1–PG8, active-low, initially all off, one LED on for 1000 ms per step (8 s/cycle).

## Import and build in CubeIDE

1. Choose a workspace outside this repository (do not copy the project into the workspace).
2. File → Import → General → Existing Projects into Workspace.
3. Select `firmware/CornerStone_LED/STM32CubeIDE` as the root directory and import `CornerStone_LED`.
4. Select the Debug configuration and Project → Build Project.
5. Confirm `App/led_app.c` is compiled and the build has zero errors. Expected output: `CornerStone_LED/STM32CubeIDE/Debug/CornerStone_LED.elf`.
6. Save the build console output for acceptance. Do not flash a stale ELF after a failed build.

No separate CMake/CLI compiler workflow is provided. Windows uses the same relative project paths and import steps, but has not been tested.

## Regeneration and application ownership

Open `CornerStone_LED/CornerStone_LED.ioc` in standalone CubeMX and Generate Code for STM32CubeIDE. Keep user code preservation enabled.

- `Inc/led_app.h` and `STM32CubeIDE/App/led_app.c` are application-owned. The C file lives physically inside the IDE project so CDT discovers it without a generated-file link modification.
- `Src/main.c` only includes the header and invokes initialization/step functions in USER CODE blocks.
- Startup, HAL, clock/GPIO initialization and linker files belong to CubeMX. Do not copy startup or linker code from the macOS/Keil branches.
- After regeneration, refresh the project in CubeIDE and build again.

## Flash from terminal

From the `firmware` directory, after a successful current IDE build:

```sh
openocd -f debug/openocd.cfg -c 'program CornerStone_LED/STM32CubeIDE/Debug/CornerStone_LED.elf verify reset exit'
```

Requires OpenOCD (tested 0.12.0) and the CMSIS-DAP adapter connected via SWD. Configuration keeps SWD at 100 kHz and overrides upstream reset handlers to avoid temporary HSI PLL programming. The application owns HSE/PLL configuration. `program` erases the sectors needed for this image; do not perform mass erase or change protection bits. Stop on detection, write or verify failure; never substitute an old ELF.
