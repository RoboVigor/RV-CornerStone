# STM32F427 / RM0090 按需阅读导航

原件：[dm00031020.pdf](originals/dm00031020.pdf)，**RM0090 Rev 22，May 2026，1741 页**。官方入口：[ST RM0090 PDF](https://www.st.com/resource/en/reference_manual/dm00031020.pdf)；网络文件可能更新，版本与哈希以仓库归档为准。

## 什么情况下需要读

- **不要求默认通读**，也不全文转成 Markdown。理解常见原理可利用已有知识；涉及准确的寄存器位、复位值、PLL/外设约束和操作顺序时，按问题读取相关章节。
- 板卡晶体频率、LED 引脚、接插件连线先查 [A 型摘要](../robomaster-a/README.md)，RM0090 不能证明板上安装了什么器件。
- F427 属于 STM32F42xxx：RCC 应查**第 6 章**，不要套用第 7 章 STM32F405/407/415/417 的 RCC 描述。
- 封装/球位/AF 映射、电气参数查器件**数据手册**；硬件限制查**勘误表**；Cortex-M4 内核细节查 PM0214 等。RM0090 p1 明确区分这些资料。本次未归档这些额外文件。
- 本地版本未覆盖、需要新版或勘误时再查 ST 官网；搜索摘要、论坛和模型记忆不能代替具体型号的官方依据。

## Agent 阅读方式

1. 根据上表选页，用 PDF 文本提取工具读取有限页段；保留 Rev 与页码作为出处。
2. 时钟树、框图、波形或文本抽取缺失时，渲染**相关单页**查看；不要把“有文字层”当成“图已读懂”。
3. 将得出的芯片约束与板卡连线、当前 `.ioc` 配置分别核对，不把任一层当成另一层的证明。
4. 如果文档与运行结果不符，报告差异和证据，不悄悄更新硬件摘要来消除矛盾。
