## 完整性验证

五份 PDF 总计 **27,106,895 bytes（约 27.1 MB）**，直接纳入 Git，不依赖 LFS。摘要和哈希仅锁定这套原件；更新 PDF 必须同步核对摘要、页码和哈希。

在仓库根目录执行：

```sh
(cd docs/hardware && shasum -a 256 -c SHA256SUMS)
```

[SHA256SUMS](SHA256SUMS) 用相对路径，可在 macOS/Linux 上校验；下载目录不属于仓库依赖。
