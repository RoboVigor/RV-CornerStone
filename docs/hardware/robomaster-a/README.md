- 查芯片型号、封装、晶体、供电、BOOT：[核心硬件事实](board-facts.md)。

- 查原理图连线、元件位置、接口朝向：打开下面的 S/P/M 原件。

## 页码规则与原理图导航

摘要中的 **PDF pN 一律为文件内从 1 开始的页序**，不是阅读器可能显示的页标签。M 中印刷页码一般比 PDF 页序小 2（例如 PDF p10 = 印刷 p8）。Q 为多语言文档，不能套 M 的偏移。

S 的 PDF p1–10 对应标题栏 **Sheet 2–11**，不能直接把 Sheet 4 当作 PDF p4；图中 `[4]` 等跨页标记也是 Sheet 编号。

| 1 | 2 | PowerTree |
| 2 | 3 | MCU A/B/C 口、SWD J1、BOOT1 |

## 证据与维护规则

1. 摘要是检索入口，不取代原件。`已核实` 仅指文档证据，实物测试单独记录。
2. 每条事实保留文件代号、PDF 页序；电路项尽量写 Sheet 和元件位号。表中以网名注明的定时器通道不是固件启用状态。
3. 已知冲突（IMU 型号、磁力计地址等）见 [冲突表](board-facts.md#必须保留的来源冲突)，不得用旧代码、常见经验或多数来源直接裁决。
4. 板卡版本未确认时，不把这套资料推广到所有 A 板修订；NC/XXX 注记不代表实物贴装已验证。
5. 更新原件或变更相关硬件配置时，核对受影响摘要及链接、页码和 [SHA-256](../SHA256SUMS)。冲突先报告，不默默改成与代码一致。
6. 不全文转录 M/R，不默认生成全部页面图片。文本不能说明连线时，只渲染相关页查看。
