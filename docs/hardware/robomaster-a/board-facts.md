# RoboMaster A 型：核心硬件事实

适用资料、来源代号与页码规则见 [资料目录](README.md)。这里描述官方资料中的板卡，不代表已测量当前实物；也不是 CubeMX 配置清单。`已核实` 指已核对来源文字/图像，不是运行验证。未覆盖内容不得用旧代码或模型记忆补齐。

## MCU 与时钟

| 项目 | 结论 | 状态与出处 |
|---|---|---|
| MCU 完整型号 | STM32F427IIH6；原理图 U1 标为 STM32F427IIH | 已核实：M PDF p5（印刷 p3）；Q p10（印刷 p9）；S p2–4，U1 |
| 封装 | IIH6 是 UFBGA，不是 IIT6 的 LQFP；ST 产品页列为 **UFBGA 176+25，10×10 mm，间距 0.65 mm** | 已核实：外部来源 W；板卡完整料号来自 M p5。板卡资料本身未完整解释封装命名 |
| Flash / RAM 概要 | U1 图符标注 2 MB / 256 KB；此处不把 256 KB 推断为一整块连续普通 SRAM | 已核实：S p2–4，U1；分区和总线访问限制按 R 第 2 章及器件数据手册查证 |
| 外部高速晶体 HSE | **X1 = 12 MHz，标注 ±30 ppm**；OSC_IN 接 PH0，OSC_OUT 接 PH1 | 已核实：S p3 / Sheet 4，左上 X1 与右上 U1C；文字与图像交叉核对。不是实测频率/精度 |
| 晶体外围 | C1、C2 各标 18 pF，接地；R10 标 1 MΩ 且带 `XXX` 注记 | 已核实图示：S p3，X1/C1/C2/R10；R10 实物是否贴装待核实，不据此给改板建议 |
| 外部低速晶体 LSE | 这份图纸中 U1A 的 PC14/PC15 标为未连接；未画出外部 LSE 晶体 | 已核实图示：S p2 / Sheet 3，U1A 底部；不能据此声称已检查实物或所有板卡版本 |
| CPU / APB 主频 | **不是晶体的固定属性**；由当前固件的时钟源、PLL 与分频决定 | 阅读边界：R 第 6 章。软件配置与历史上板证据另见根 AGENTS.md、firmware 文档，本页不复制为硬件定值 |

W：[ST STM32F427II 官方产品页](https://www.st.com/en/microcontrollers-microprocessors/stm32f427ii.html)，本次核对 STM32F427IIH6 与 STM32F427IIT6 的订货表。该网页未离线归档；机械尺寸与引脚复用的工程使用仍应核对数据手册，不以 RM0090 代替。

## 供电与接口电平

| 项目 | 结论 | 状态与出处 |
|---|---|---|
| 输入 | 最大 26 V；支持 4–6S LiPo；电源输入为 XT30 | 已核实：M p7–8（印刷 p5–6），Q p13（印刷 p12）。保护电路阈值不等于允许输入电压 |
| 持续输入电流 | 最大允许 20 A，条件为室温 25℃、通风良好的实验环境 | 已核实：M p7、Q p13；不是任意散热条件下的承诺 |
| 四路可控电源输出 | 单路不超过 10 A，四路合计不超过 20 A；分别由 PH2–PH5 控制 | 已核实：M p18（印刷 p16），S p7 / Sheet 8；连接器/走线图上的 15 A、20 A 标签不能替代此限制 |
| 12 V 输出 | 有 12 V DC-DC 电源，手册给最大 10 A，附实验条件及过流注意事项 | 已核实：M p19（印刷 p17）；不是每个输出口各有独立 10 A 额度 |
| 16 路 PWM 供电 | 共用可调电源，默认约 5 V，手册给 5 A 驱动能力；拨码可改变电压 | 已核实：M p16（印刷 p14），S p9 / Sheet 10；不是每路 5 A，也不是固定 5 V。接舵机前回查拨码表 |
| 串口电平 | 手册说明支持 3.3 V / 5 V 电平；RS232、RS485 需外置电平转换 | 已核实：M p9（印刷 p7），§1.4；不扩大为所有 MCU 引脚均耐 5 V |
| SWD | J1 的接口电源为 3.3 V，SWDIO/SWCLK 各串联 100 Ω；PA13/PA14 是 MCU 对应信号 | 已核实：M p9 §1.3，S p2 / Sheet 3，J1/R3/R4/U1A。不要向该接口接入 5 V；实际下载器供电方式按其说明核对 |

## BOOT、复位和基础交互

| 项目 | 结论 | 状态与出处 |
|---|---|---|
| 默认 BOOT | BOOT0、BOOT1 默认下拉，User Flash 启动；R17、R1 上拉位置标 NC | 已核实：M p10–11（印刷 p8–9），S p2 / Sheet 3（R1/R2）、p4 / Sheet 5（R17/R18） |
| 启动选择 | BOOT0=0 → Main Flash；BOOT0=1、BOOT1=0 → System memory；二者=1 → SRAM | 已核实：M p11 启动表，S p4 启动表。手册将 System memory 路径用于 DFU；不等于只改引脚就完成了 USB 下载环境配置 |
| 用户按键 | S1 → PB2，按下为高电平；PB2 同时是 BOOT1 | 已核实：M p10 §1.7，S p2 U1A、p5 S1；注意它不是复位按键 |
| 复位按键 | SW1 → NRST，图示按下接地 | 已核实：S p4 / Sheet 5，SW1/R19/C13；M p10 §1.7 |
| 用户 LED | 8 颗绿色 PG1–PG8，另有绿色 PF14、红色 PE11；均为低电平点亮 | 已核实：M p10 §1.5–1.6；S p3 / Sheet 4，AD1–AD8、D9/D10（阳极接 3.3 V，经电阻回 MCU） |
| 蜂鸣器 | PH6 / TIM12_CH1 驱动 LS1，手册给额定频率 2700 Hz | 已核实：M p12 §1.10，S p6 / Sheet 7，LS1/Q4；不提供初始化/占空比配置 |

- 图纸标题栏的 `<RevCode>` 占位符不是有效版本号；各 Sheet 日期不同，不据此虚构统一 PCB 版本。
- 未独立校验每一个 MCU 图符的全部复用功能、球位文字和每个插座的物理朝向。摘要仅覆盖已列项目。
- 芯片电气极限、AF 编号、勘误、传感器寄存器与 CubeMX 配置另行核验；本次没有下载额外数据手册、修改固件或测试硬件。
